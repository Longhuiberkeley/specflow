# Qualification Test for REQ-029: Competition-scoped experiment tracking

Backfilled qualification test for REQ-029 (Competition-scoped experiment tracking).

## Test Reference

- tests/test_autoresearch_pack.py — exercises the chain: COMP→LOOP→3 EXPTs→FIND with the correct link roles (operates_on, belongs_to) confirmed.
- tests/test_trace_research.py — exercises specflow trace COMP/LOOP/EXPT/FIND using the link-role contract from ARCH-023 (operates_on, belongs_to, condenses).
- tests/test_artifacts.py — exercises the specflow create / update paths that the chain depends on.

## Scope

REQ-029 requires every experiment to be recorded as an EXPT linked to a parent LOOP, which is in turn linked to a COMP. Without per-competition scoping, experiments from different problems (e.g., screener competition vs validator competition) become mixed and FINDs lose context.
