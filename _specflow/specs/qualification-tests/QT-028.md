# Qualification Test for REQ-027: Discovery-to-Plan Skill Continuity

## Test Cases

- [ ] 1. Given a discovery session that applies thinking techniques to challenge requirements, when the session produces assumptions, risks, or dropped requirements, then those results **shall** be persisted as decision artifacts so they are available to the plan skill.
- [ ] 2. Given requirements with dependencies between them (e.g., REQ-005 depends on REQ-002), when the discovery skill completes, then inter-REQ dependencies **shall** be captured as `derives_from` links between requirement artifacts.
- [ ] 3. Given a project with a domain classification set during discovery, when the plan skill reads requirements, then the plan skill **shall** consume the domain classification and tags to scope its decomposition approach.
- [ ] 4. Given the discover skill's exit, when the user is informed of next steps, then the exit message **shall** explicitly state which requirements need approval before planning can begin and provide the command to approve them.
