# Qualification Test for REQ-001: Knowledge-surface visibility & consumption

Backfilled qualification test for REQ-001 (Knowledge-surface visibility & consumption).

## Test Reference

- tests/test_knowledge_lifecycle.py — exercises the knowledge lifecycle end-to-end: PREV patterns created from FINDs are loaded by checklists; BP matching by tag and applies_to selects exactly one canonical matcher; nonmatching, draft, and superseded BPs are excluded; checklist and agent context share canonical matches so assembled practices are not duplicated into the review prompt.
- tests/test_brief.py — exercises the brief consumption path: with all knowledge surfaces empty, brief still renders the Knowledge surfaces block with zero counts and advisory dormancy hints; the BP dormancy hint fires only when no active BP exists; the artifact inventory is discovered exactly once.

## Scope

REQ-001 covers the CLI surface that carries the knowledge lifecycle, including `specflow brief`, the deterministic recall point. The BP (proactive) and PREV (reactive) knowledge surfaces must be visible even in the empty state, matched by exactly one canonical matcher, and consumed through the brief, checklist, and review paths without duplication. This qualifies the visibility-and-consumption slice of STORY-082 at the REQ level; that story closes against REQ-001 and REQ-005, and its Test Strategy names exactly these two test files.

## Acceptance Criteria

1. uv run pytest tests/test_knowledge_lifecycle.py tests/test_brief.py -q exits 0 (recorded via specflow verify).
2. Empty-state brief renders the Knowledge surfaces block with zero counts and advisory dormancy hints.
3. A matching active/approved BP is selected by one canonical matcher and judged exactly once; nonmatching, draft, and superseded BPs are excluded.
