# Qualification Test for REQ-015: Ship-grade evidence RTM

Backfilled qualification test for REQ-015 (Compliance Evidence Reports — ship-grade evidence RTM).

## Test Reference

- tests/test_evidence.py — exercises the compliance evidence report generator: basic report generation and missing-baseline handling; the traceability section rendering approved, implemented, and verified requirements together in one deterministic matrix; the mixed-status regression proving the first verified REQ no longer collapses the matrix to one row; the test-results, standards-compliance, and baseline-diff sections.

## Scope

REQ-015 requires `specflow ship --evidence` to emit a deterministic compliance evidence report whose traceability matrix covers every eligible requirement. The generator previously preferred verified REQs and fell back to approved/implemented only when none were verified, so the first verified REQ collapsed the ship-grade RTM from the full traceable set to one row. STORY-KEEPRELE-37de fixed this by rendering approved + implemented + verified requirements together in one matrix and adding the mixed-status regression. This QT qualifies that behavior at the REQ level.

## Acceptance Criteria

1. uv run pytest tests/test_evidence.py -q exits 0 (recorded via specflow verify).
2. The evidence report traceability matrix includes approved, implemented, and verified requirements in one deterministic matrix.
3. A mixed-status project retains every eligible REQ when at least one is verified.
