## Scope

Qualifies the CHL-NONSEMVE-c16b policy at the requirement level: drift comparisons prefer semver-parseable release baselines everywhere a pair is selected (audit drift, evidence predecessor), new baselines must be version-shaped, existing freeform baselines stay usable, and the audit exit code remains a pure function of findings with --dry-run writing nothing.
