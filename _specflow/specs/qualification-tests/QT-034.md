# Qualification Test for REQ-033: Dynamic status dashboard for new artifact categories

Backfilled qualification test for REQ-033 (Dynamic status dashboard for new artifact categories).

## Test Reference

- tests/test_autoresearch_pack.py — exercises the dynamic dashboard: when the autoresearch pack is installed, the four research artifact types (COMP/LOOP/EXPT/FIND) are grouped under the research category in specflow status, with no code edits to status.py.
- tests/test_brief.py — exercises brief --next's category-aware counting: the brief surfaces the research category with its counts as one of the groups.
- tests/test_artifact_lint.py — exercises the lint path that walks the same category-aware schema metadata.

## Scope

REQ-033 requires the specflow status dashboard to group artifact rows dynamically based on a category field in each schema YAML. Today specflow status hardcodes prefix lists; adding research artifact types should not require code changes — packs declaring new types should be displayed automatically.
