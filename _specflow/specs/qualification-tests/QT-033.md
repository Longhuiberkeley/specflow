# Qualification Test for REQ-032: Pack system supports skill installation

Backfilled qualification test for REQ-032 (Pack system supports skill installation).

## Test Reference

- tests/test_adoption_pack.py — exercises the add_pack adoption path: skills declared in pack.yaml adds_skills are copied to .claude/skills/, user-edited skills are not clobbered on reinstall, and the field is recognized as a valid pack.yaml key during adopt.
- tests/test_autoresearch_pack.py — exercises apply_pack()'s skill-installation step in the autoresearch pack install lifecycle.
- tests/test_ops_pack.py — exercises the peer ops pack install to confirm the skill-installation mechanism is general.
- tests/test_refresh_lints.py — exercises the refresh path that re-installs the pack's skills into an existing project.

## Scope

REQ-032 requires the pack system to support skill installation via an adds_skills field in pack.yaml. Today only schemas, directories, checklists, and standards can be packaged; skills (the conversational interface) must be packaged for any non-core capability to ship as a true plug-in.

## Acceptance Criteria

1. uv run pytest tests/test_adoption_pack.py tests/test_autoresearch_pack.py tests/test_ops_pack.py -q exits 0 (recorded via specflow verify).
2. Skills declared in adds_skills are copied on first install.
3. Re-running apply_pack on a project with user-edited skills does not clobber them.
4. specflow artifact-lint --method programmatic adds 0 blocking issues.
