# Qualification Test for REQ-026: Decomposition Completeness Guidance

## Test Cases

- [ ] 1. Given a set of stories tagged with SPIDR dimension labels (e.g., `spidr-path`, `spidr-data`), when `specflow artifact-lint` is executed, then the system **shall** report a warning if any of the five SPIDR dimensions produced no stories.
- [ ] 2. Given stories with `depends_on` links, when `specflow artifact-lint` is executed, then the system **shall** detect and report circular dependencies between stories.
- [ ] 3. Given a project without an LLM API key configured, when `specflow handbook generate` is executed, then the system **shall** provide bundled generic best practices as a fallback rather than failing.
- [ ] 4. Given the plan skill documentation, when a user reviews the DDD selection guidance, then a decision tree **shall** exist with criteria for determining whether an architecture component requires a detailed design artifact.
- [ ] 5. Given the plan skill workflow, when architecture discussion produces significant technology or structural choices, then the skill **shall** create traceable decision artifacts.
