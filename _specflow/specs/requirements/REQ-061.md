# Shipped prose matches the engine contract — wave 2

## Context

REQ-056 (verified at v1.17.0) made shipped skills executable as documented. The 2026-10 audit found a second layer of drift: the plan skill teaches the `ARCH derives_from REQ` link shape that lint reports as legacy, link-roles.md calls itself a complete vocabulary while omitting six schema roles, the audit skill names a CHL status that does not exist, the adapter skill calls a blocking hook advisory and claims init regenerates CODEOWNERS, discover's lean path creates a draft STORY its exit message never approves, start routes approved-REQ work to execute, and several references carry stale step pointers, host-specific tool names and dead preset guidance. Owner decision 2026-10-08: skills teach `REQ refined_by ARCH`.

## Constraints

- Every edit lands in `src/specflow/templates/skills/shared/` and the `.claude/skills/` mirror stays byte-identical.
- Core SKILL.md budgets (DEC-083/ARCH-030) are respected; prose moves to references rather than growing routers.
- Each corrected claim gets a deterministic guard test where one is cheap.

## Acceptance Criteria

- [ ] AC1: The plan skill links ARCH to REQ with `specflow update <REQ> --add-link <ARCH>:refined_by`; `rtm.py` and the link-roles/escalation references state the same REQ→ARCH and ARCH→DDD directions.
- [ ] AC2: Every role in any shipped schema's `allowed_link_roles` appears in link-roles.md, pinned by a test with an explicit pack-role exemption list.
- [ ] AC3: No core skill names a status, subcommand or flag the CLI rejects (`done` for CHL, bare `specflow patterns`, "advisory" hook, CODEOWNERS regeneration), pinned by the existing prose-CLI surface tests.
- [ ] AC4: Discover's lean path exit message approves both REQ and STORY and routes to execute; the start router distinguishes no-REQ / approved-REQ-no-STORY / approved-STORY cases.
- [ ] AC5: Discover carries a conflict-check step against existing REQs/DECs/README/code and a DEF path for bug reports targeting an approved REQ; ship carries an advisory verification step and attributes handoff items as engine / this repo / you.
- [ ] AC6: The defect status map allows `open → fixing`; status-lifecycle.md lists `wontfix`; wave-computation.md lists `depends_on`.
