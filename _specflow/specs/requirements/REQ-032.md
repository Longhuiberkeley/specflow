# Pack system supports skill installation

The pack system **shall** support skill installation via an `adds_skills:` field in `pack.yaml`.

## Acceptance criteria

- `pack.yaml` accepts an `adds_skills: [<skill-name>, ...]` field
- `apply_pack()` copies each named skill directory from `pack_root/skills/<name>/` to the platform-specific skills directory (resolved via `platform.get_skills_dir()`)
- Skill files follow the existing no-overwrite policy (user edits preserved on pack reinstall)
- The capability is generic — any future pack (not just autoresearch) can ship skills
