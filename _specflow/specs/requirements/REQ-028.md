# Autonomous experimentation loop on SpecFlow

The system **shall** support running an autonomous agent that iterates against a defined competition (dataset + metric + verify command), producing structured experiment records and condensed knowledge artifacts.

## Acceptance criteria

- A user can declare a competition (dataset, metric, verify command) and start an autonomous loop against it
- Each loop iteration produces one EXPT artifact with a terminal status (kept / discarded / crashed / no_op)
- After a loop completes, FIND artifacts capture what worked, what failed, and next steps
- Subsequent loops on the same competition read prior FINDs before ideation
- The system supports 1000+ experiments per competition without degradation

## Out of scope (v1)

- Fresh-mode orchestrator/worker (deferred — see DEC)
- Cross-competition automation (manual workflow only)
- Auto-generated FIND drafts (manual, agent-driven in v1)
