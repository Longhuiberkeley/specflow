# Dynamic status dashboard for new artifact categories

The `specflow status` dashboard **shall** group artifact rows dynamically based on a `category:` field in each schema YAML.

## Acceptance criteria

- Each schema YAML gains an optional `category:` field; missing values default to `spec`
- Default categories: `spec` (REQ/ARCH/DDD/UT/IT/QT), `work` (STORY/SPIKE/DEC/DEF), `review` (REVIEW/AUD/CHL), `research` (COMP/LOOP/EXPT/FIND)
- A category row is rendered only if at least one artifact in that category exists
- Backward compatible: existing displays unchanged when no research artifacts present
