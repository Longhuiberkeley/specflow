# Deterministic next-step and digest honesty

## Context

`specflow brief --next` is the memory digest every session starts from, yet it printed "Continue /specflow-execute" with zero approved STORYs (live on this repo), had no branch for open DEFs or draft DECs, and named raw CLI where a skill exists. Consumer sessions received the same recommendation 19 times over 8 days while the real work was elsewhere ("TLDR? like what's next?"). Related read-only reports (change-impact, rtm --gaps, verify --all --dry-run, adopt status, status dashboard, fingerprint-refresh) print stale or inflated signals, and `brief` and `artifact-lint` disagree on practice bindings.

## Constraints

- Signals stay advisory (accounting-not-policing); a quiet project prints no new lines.
- No persisted state is added for age markers; recommendations are a pure function of the repository.
- D-18 vocabulary frozen; no mode toggles.

## Acceptance Criteria

- [ ] AC1: With every non-terminal STORY implemented or verified, `brief --next` routes to review/ship; with zero approved and zero implementable STORYs it routes to `/specflow-plan`, never to `/specflow-execute`.
- [ ] AC2: `brief --next` appends a note naming open/fixing DEF counts and IDs, non-auto draft DECs with the exact approval command, and approved-but-unexecuted STORYs in verifying/complete, each only when non-empty.
- [ ] AC3: Suspect and unreviewed-DEC branches of `brief` lead with `/specflow-change-impact-review`.
- [ ] AC4: `brief` and `artifact-lint --type bp-application` report the same unbound practice-binding count on this repo.
- [ ] AC5: `change-impact` prints no "Unresolved Suspect Flags" header or "Oldest unresolved flag" when every unresolved event flagged nothing; `fingerprint-refresh` on an unchanged artifact writes no event and bumps no version.
- [ ] AC6: `rtm --gaps` hides terminal-status REQs with a footer count; `verify --all --dry-run` prints one summary line for contract-less artifacts; `project-audit --dry-run` prints warning and error findings.
- [ ] AC7: `brief` reports when installed skills differ from the shipped templates and when a top-level inventory bucket is concentrated in one or two types.
- [ ] AC8: The findings-baseline policy table classifies coverage/no-test, links/missing-v-pair and bp-application/no-test as accounting for draft/approved STORYs and wave-cycles/fan-in and story-size as accounting always, recorded by a DEC amending DEC-099; a fresh `init` at discovering/planning/executing lints PASS with an empty baseline.
