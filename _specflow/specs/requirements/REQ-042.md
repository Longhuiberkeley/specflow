# Model-facing context is minimal, tool-enforced, and artifact-native

## Requirements

R1 Always-on budget: agent-context.md + installed pack snippets total ~500 tokens or fewer; every line earns its place.
R2 Skill catalog: every SKILL.md frontmatter description is a one-line narrow trigger (the situation where the skill is REQUIRED); no keyword walls, no NOT-for lists.
R3 Consent is seek-and-proceed: approval-gated statuses are presented with exact IDs and one-line impact, then proceed on go-ahead; delegated autonomy performs and lists each approval. approve --type output must list exact draft IDs + impact to be a valid consent vehicle.
R4 Prompt rules that duplicate CLI enforcement (checklist assembly, status maps, wave ordering) are cut; unenforced claimed gates either get a CLI backstop or are deleted (never left as prompt-only false security).
R5 Knowledge is artifact-native per DEC-082: context points at specflow brief / artifact IDs, never at docs/ paths; docs/ is at most derived rendering.

## Verification

- pytest tests/ green (template content assertions updated where they pin old wording)
- specflow artifact-lint + project-audit green
- Token count of agent-context.md + pack snippets <= 500

## Acceptance Criteria

Given this repository, when pytest tests/ runs, then all tests pass with the re-anchored guardrail pins (test_approval_guardrail, pack snippet pins).
