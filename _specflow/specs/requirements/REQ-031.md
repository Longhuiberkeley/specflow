# Explore / exploit / validate LOOP modes

Each LOOP **shall** declare one of three modes that influences the agent's ideation behavior in Phase 2 of the loop protocol.

## Modes

- **explore**: try fundamentally different approaches; read FIND `what_failed` to avoid repeats
- **exploit**: refine the current best; read FIND `what_worked` for direction
- **validate**: re-run best approaches, possibly on different data/config

## Acceptance criteria

- LOOP schema has a required `mode` field with enum {explore, exploit, validate}
- The skill's `explore-exploit-protocol.md` reference documents when each mode is applicable based on loop count and metric trend
- The user explicitly sets the mode at LOOP creation (no auto-selection in v1)
