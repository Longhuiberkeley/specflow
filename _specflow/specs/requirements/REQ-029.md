# Competition-scoped experiment tracking

The system **shall** record every experiment as an EXPT artifact linked to a parent LOOP, which is in turn linked to a COMP.

## Acceptance criteria

- Every EXPT has a required `loop` field referencing a LOOP ID
- Every LOOP has a required `competition` field referencing a COMP ID
- `specflow trace COMP-NNN` walks down to LOOPs and EXPTs
- An EXPT's metric_value, change_category, and summary are queryable across all EXPTs in a COMP
