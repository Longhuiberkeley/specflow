# Knowledge condensation across loops

The system **shall** support FIND artifacts that condense the learning from one or more LOOPs into a structured summary.

## Acceptance criteria

- FIND artifacts have what_worked, what_failed, next_steps, confidence, and applies_to fields
- FINDs live at the competition level (linked to COMP, not LOOP)
- A FIND may reference a single LOOP via source_loop, or be a cross-loop synthesis (source_loop optional)
- Each new LOOP records the FIND IDs it read into its knowledge_input field
- FIND status lifecycle: draft → confirmed → (superseded | falsified)
