# Deterministic checks are zero-token shell or Python; never LLM inference for a pass/fail signal

## Practice
Any check that gates a transition, warns in an audit, or appears in the commit hook must be a deterministic local script (shell/Python reading the artifact graph). LLM inference may surface nuance, but a pass/fail/warn signal must be reproducible with no external API call.

## Rationale
SpecFlow is self-contained and host-agnostic. An LLM-dependent signal is non-deterministic, costs tokens, varies by host/model, and cannot run in clean CI. Cry-wolf false positives (the #1 dogfood friction) come from weak deterministic signals — the fix is stronger behavioral conditions, not LLM judgment.

## Verification
Every check in `.specflow/checklists/` and the pre-commit hook either runs a script or is marked `automated: false` (advisory only). `grep` finds no LLM/API call on any code path that sets a pass/fail result. `specflow project-audit` exits deterministically.
