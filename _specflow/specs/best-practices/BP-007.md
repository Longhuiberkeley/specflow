# Recall before you act: run specflow brief first on any fresh or vague prompt

## Practice
On any fresh or vague prompt, the first move is `specflow brief` (or `specflow brief --next`), then breadth-first index scans, then reading specific bodies — never the reverse. Do not guess the phase or inventory from memory.

## Rationale
A fresh session has no reliable memory; the artifact graph is the memory. `brief` is a fixed-size deterministic digest that reconstructs project state in one call. Scanning bodies by hand re-reads what the indexes already summarize and misses cross-cutting state (suspects, next wave, recent decisions).

## Verification
A fresh session orienting on a vague prompt runs `specflow brief --next` before editing or proposing. Drill-down (trace/status/artifact-lint) follows brief, not precedes it. AGENTS.md "Recall before you act" is honored.
