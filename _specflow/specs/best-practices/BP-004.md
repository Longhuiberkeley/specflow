# Capture an evidence baseline before changing; re-run the same gate after; report the delta

## Practice
Before making a change, capture the current gate state (test pass/fail counts, or `specflow artifact-lint` counts if there is no test runner). After the change, re-run the SAME gate and report the before→after delta. Never claim "no regressions" without a captured baseline to diff against.

## Rationale
"Verified" is a claim, not a proof. Without a captured baseline, an agent cannot tell whether a post-change green run reflects no regressions or a test that was already failing/missing. Diffing the same gate before and after is the only honest evidence.

## Verification
The STORY/DEC record quotes concrete before and after numbers from the same command (e.g. "682 passed" → "685 passed"), or `specflow artifact-lint` counts before/after. A bare "tests pass" without a baseline fails this check.
