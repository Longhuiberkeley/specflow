# specflow verify arc: evidence recorder + verify_run_* persistence

## Test Reference

`tests/test_verify.py`

## Scope

Backfilled verification contract for STORY-623 ("Verification arc: specflow
verify + verify_run_* evidence + entry-point sync"). The recorder half ships as
the `specflow verify` command and the `lib/verification.py` evidence writer;
`tests/test_verify.py` exercises the recording path end to end.

- Dispatch: `specflow verify <ID>`, `--all`, `--type UT/IT/QT/STORY`,
  `--dry-run`, `--evidence-file`, `--timeout`, `--seed-prev`.
- Recorded fields: `verify_run_at`, `verify_run_exit_code`,
  `verify_run_evidence` are written to the artifact's frontmatter.
- Failing-run invariant: a non-zero exit code is recorded, never blocking, and
  does not escalate audit findings.

## Acceptance Criteria

1. `uv run pytest tests/test_verify.py -q` exits 0 (recorded via
   `specflow verify`).
2. `specflow verify` writes the recorded run fields; `--dry-run` executes
   nothing and writes nothing.
3. A failing `verify_command` records its real exit code and does NOT block
   any commit, transition, or release.
