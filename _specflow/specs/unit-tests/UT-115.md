# V-pair paired-test-type unit pins (STORY-680)

tests/test_coverage_semantics.py: TestVPairRequiresPairedTestType covers these cases. A non-test verifier and a wrong-level test leave the spec unpaired. An incoming paired test pairs it, and so does the spec's own outgoing verified_by to the paired type. An outgoing link to the wrong type does not. The returned prefix is the paired test prefix (QT/IT/UT).
