# DDD-023 unit tests: pack.yaml adds_skills field semantics

Backfilled verification contract for DDD-023 (pack.yaml adds_skills field — semantics and install behavior).

## Test Reference

- tests/test_adoption_pack.py — exercises the adds_skills install behavior: skills declared in pack.yaml are copied to the .claude/skills/ tree, user-edited skills are not clobbered on reinstall, and the field is recognized as a valid pack.yaml key during adopt.
- tests/test_autoresearch_pack.py — exercises apply_pack()'s skill-installation step in the autoresearch pack install lifecycle (TestPackInstall covers copy schemas + create dirs + install skills as one atomic op).
- tests/test_refresh_lints.py — exercises the refresh path that re-installs the pack's skills into an existing project without wiping user edits.

## Scope

DDD-023 defines the adds_skills field's behavior across install, reinstall, and upgrade:
- declared skill names map to source files in pack_dir/skills/
- files are copied to .claude/skills/<name>/ (creating dirs as needed)
- existing user files are not overwritten
- the field is optional; absence means no skill installation

## Acceptance Criteria

3. Re-running apply_pack on a project with user-edited skills does not clobber the user files.
