# Unit Test for DDD-032: Practice loader and transitional status map semantics

## Test Cases

- [ ] Given a BP with both an applicability predicate and tags, when the practice loader resolves BPs, then applicability matches first, tags are the fallback, and the approved-status filter applies last
- [ ] Given a legacy BP in status `active`, when lint checks the best-practice status map, then the transitional map accepts it and both transitional edges stay reachable
- [ ] Given BPs without provenance, when `specflow practices migrate --dry-run` runs, then it prints the would-stamp set with counts, exits 0 and writes nothing; a real run is idempotent
- [ ] Given the shipped dogfood BPs, when the new loader and the legacy path resolve them, then the selections are equal
