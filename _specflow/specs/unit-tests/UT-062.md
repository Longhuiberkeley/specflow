# DDD-028 unit tests: deferred lifecycle capabilities detailed design

Backfilled verification contract for DDD-028 (deferred lifecycle capabilities — command-surface detailed design).

## Test Reference

- tests/test_phase_set.py — exercises specflow phase-set's forward/rewind transition history (records to state history without gating, clears execution state on leaving executing).
- tests/test_rtm.py — exercises specflow rtm's bidirectional REQ→ARCH→STORY→tests walk with per-column gap markers and --gaps filter.
- tests/test_rbac_check.py — exercises specflow rbac check's author→roles resolution and transition authorization (single-user projects get a clear not-active message with exit 0).
- tests/test_supersession.py — exercises the supersession status and supersedes role for REQ/ARCH/DDD schemas.
- tests/test_lint_quality_gates.py — exercises the AC/NFR lint parsers (empty-AC error, NFR threshold warning).
- tests/test_multi_platform.py — exercises the multi-host platform detection warning and refresh --all-platforms.

## Scope

DDD-028 refines ARCH-028 into the six concrete command surfaces. Each one is an accounting/recording surface over the existing artifact graph — none becomes a gate. Data models, algorithms, and exit-code contracts are detailed per surface.
