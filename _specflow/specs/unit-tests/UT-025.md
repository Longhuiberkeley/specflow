# Unit Test for DDD-019: Source File to Artifact Reverse Mapping Algorithm

## Test Cases

- [ ] Given a literal `output_files` entry, when the index matches a changed path, then only that exact path matches
- [ ] Given glob entries using `*`, `?`, `[...]` and `**`, when matched, then `*` stays within one path segment, `**` spans zero or more directories, and no false positive is returned
- [ ] Given duplicate matches across entries, when reverse impact runs, then each artifact is reported once
- [ ] Given an empty changed-file list, when reverse impact runs, then no artifact is returned or flagged
