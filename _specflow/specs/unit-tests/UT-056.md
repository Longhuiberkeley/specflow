Backfilled verification contract for DDD-022 (Schema definitions for COMP / LOOP / EXPT / FIND).

- tests/test_autoresearch_pack.py — exercises the COMP/LOOP/EXPT/FIND schema lifecycle (valid/invalid statuses + transition structure), pack install that copies schemas and creates the four artifact dirs, EXPT terminal-status coverage (all 4 EXPT statuses valid, none allow transitions), and end-to-end COMP→LOOP→3 EXPTs→FIND.

- required vs optional field recognition in specflow artifact-lint
- status transitions per type (EXPT terminal; COMP/LOOP/FIND movable)
- round-trip on disk through update_artifact
