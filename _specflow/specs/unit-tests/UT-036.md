# Pre-adoption baseline handshake: ops pack + monitor/run schemas

## Test Reference

`tests/test_ops_pack.py`

## Scope

Backfilled verification contract for STORY-625 ("Pre-adoption baseline
traceability"). The v1.10.0 ops pack (pack.yaml, monitor/run schemas) is the
documented baseline residue bucket for files that predate STORY adoption.
`tests/test_ops_pack.py` exercises the pack schema, the monitor/run schema
validation, and the load/render path.

- `src/specflow/packs/ops/pack.yaml` — ops pack manifest.
- `src/specflow/packs/ops/schemas/monitor.yaml` — monitor pack schema.
- `src/specflow/packs/ops/schemas/run.yaml` — run pack schema.
- `tests/test_ops_pack.py` — exercises schema validity, command dispatch, and
  rendering.

   not by demotion.
