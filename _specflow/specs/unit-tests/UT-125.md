# Unit tests: rename-following file history, upto-scoped independence, per-step legality (STORY-698)

tests/test_rbac.py TestFileHistory: git_utils.file_history follows a renumber-drafts rename oldest-first (A then R with the draft old_path), loses pre-rename history with follow=False, and returns None for an unknown ref. TestCheckIndependenceHistory: check_independence sees the implementer across the rename (case-insensitive); upto= (SHA or ref name) excludes the transition commit's own author, while the no-upto pre-commit semantics still read all of HEAD. tests/test_hook.py: _illegal_step_reason accepts legal steps (including a bare-string predecessor), names the allowed predecessors for an illegal jump, rejects an unknown target status, and does not judge creation, the invalid-current-status repair path, or a type without a schema.
