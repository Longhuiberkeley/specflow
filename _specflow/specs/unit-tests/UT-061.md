# DDD-027 unit tests: autoresearch pack detailed design

Backfilled verification contract for DDD-027 (autoresearch pack — schema field contracts, CLI dispatch, context injection, domain-aware lint).

## Test Reference

- tests/test_autoresearch_schema.py — exercises the four schema field contracts: EXPT auxiliary_metrics (optional freeform YAML dict), multi-criteria competition fields, platforms.yaml instruction_file, and context_snippet's idempotent sentinel injection.
- tests/test_autoresearch_cli.py — exercises the autoresearch CLI subcommand dispatch: specflow autoresearch plan/run/review/leaderboard against multi-COMP repos (--competition, --all) and the concurrent-LOOP gate.
- tests/test_adoption_pack.py — exercises the add_pack adoption path that sets up the schema + skills + context injection.
- tests/test_refresh_lints.py — exercises the refresh path that re-installs the pack's skills and re-lints.
- tests/test_autoresearch_pack.py — exercises the pack lifecycle (apply_pack, reinstall, end-to-end chain) that ties the four contracts together.

## Scope

DDD-027 refines ARCH-027 into the four concrete contracts:
1. auxiliary_metrics (EXPT schema) — optional, freeform, lint-recognized.
2. multi-criteria competition (COMP schema) — primary metric + guards + auxiliary logging.
3. context_snippet (pack.yaml) — injected into instruction files with idempotent sentinels.
4. platforms.yaml instruction_file — per-platform override of the context-injection target.

Plus: the autoresearch CLI subcommand dispatcher, the --set write path that uses the same field setter as create, and the domain-aware lint algorithm.
