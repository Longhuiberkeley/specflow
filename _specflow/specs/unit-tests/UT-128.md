# Index-store crash-at-k harness: every write of create, update, rebuild-index, renumber-drafts, lint --fix, merge, split and practices migrate re-runs to the clean state (STORY-696)

tests/formal/test_index_store_crash.py counts every call to Path.write_text, Path.write_bytes, os.replace, os.rename (Path.rename) and os.link during a clean run of each mutating command, then for every k crashes the k-th write (raise before it, or write half the payload then raise) with a BaseException, re-runs the same command and requires the normalised end state to equal an uncrashed history (the command once, or twice when the crashed attempt had fully committed) with I1 and I4 holding (DDD-034 I5). A fidelity canary proves the counter sees each patched primitive.

tests/formal/test_index_store_allocators.py forces a same-number collision in the PREV, baseline and impact-log allocators and requires exclusive create (I2). tests/test_single_index_writer.py is the AST writer ban: only specflow.lib.locks may write _index.yaml, the quarantine, state.yaml, PREV patterns, baselines, impact-log events or the renumber journal (AC2). tests/test_safety_claims_cite_tests.py requires any safety claim in src/ docstrings or comments to cite a tests/ path (AC7); both carry seeded-violation fixtures.
