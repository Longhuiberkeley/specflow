## Scope

STORY-076's AC 5 adds the `_check_autoresearch_logging` artifact-lint check and AC 10 adds `hypothesis`/`hypothesis_outcome` logging on experiments. This contract pins both enforcement surfaces: domain-aware auxiliary-metric / parameters / failure_analysis warnings (TestAutoresearchLoggingLint) and hypothesis / hypothesis-outcome completeness warnings (TestAutoresearchHypothesisLogging). Both classes drive the same `_check_autoresearch_logging` lint function, which is the single enforcement point for autoresearch logging gaps.
