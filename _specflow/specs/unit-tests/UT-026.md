# Unit Test for DDD-020: SPIDR Coverage, Wave Validation, and Generic BP Fallback

## Test Cases

- [ ] Given stories covering all five SPIDR dimensions, when `_check_spidr_coverage` runs, then it reports no warning; given only `spidr-path`, then it warns about the 4 missing dimensions

- [ ] Given a dependency cycle between stories, when `_check_wave_cycles` runs, then it names the cycle; given a story with more than 3 dependencies, then it advises restructuring, except where the dependency is already verified
- [ ] Given acyclic stories, when the wave check runs, then the wave survey lines are info-marked and group stories by wave
