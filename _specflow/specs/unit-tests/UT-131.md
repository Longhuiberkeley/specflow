# Grep ban: artifact status is written only through artifacts.update_artifact, no merged_into anywhere in src (STORY-697 AC5)

tests/test_status_write_ban.py scans every module under src/specflow except the allowlisted lib/artifacts.py (update_artifact and its helpers) for direct status writes: a frontmatter subscript assignment (fm/frontmatter/front_matter/meta/header ["status"] =), a _update/_set/_write_frontmatter_field call carrying "status", a .replace/re.sub substitution of a status: line, a frontmatter .update/.setdefault carrying "status", and the merged_into pseudo-status literal. Seeded violations prove each pattern fires; the sanctioned forms (an updates dict handed to update_artifact, an autoresearch agenda record, an equality read, update_artifact(status=...)) are not matched. Run against the v1.16.0 source (git archive HEAD) it fails on lib/impact.py:529 (_update_frontmatter_field(source_path, "status", "merged_into")) and the cli.py merge help string; it passes on the fixed tree.
