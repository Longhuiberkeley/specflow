# DDD-025 unit tests: autonomous loop protocol 8 phases

Backfilled verification contract for DDD-025 (Autonomous loop protocol — 8 phases).

## Test Reference

- tests/test_autoresearch_cli.py — exercises the 8-phase loop via the four CLI verbs: plan (creates/updates a LOOP with mode+budget+knowledge_input), run (executes the protocol against a COMP), review (displays FINDs/EXPTs), leaderboard (ranks EXPTs by metric). The concurrent-LOOP gate refuses to start a second LOOP on the same COMP.
- tests/test_autoresearch_pack.py — exercises the same 8-phase flow at the artifact level: TestEndToEndChain walks COMP→LOOP→3 EXPTs→FIND and confirms each phase's output artifact exists and is link-correct.
- tests/test_trace_research.py — exercises the trace rendering that the review phase uses to walk COMP→LOOP→EXPT and COMP→FIND chains.

## Scope

DDD-025 defines the 8-phase protocol: plan (set mode+budget), run (execute), record (EXPT), reflect (FIND), gate (concurrent-LOOP refusal), review (chain walk), commit (atomic), reset (cleanup). The tests lock in the artifact-level invariants per phase and the cross-phase link integrity.
