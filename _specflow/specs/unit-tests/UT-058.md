# DDD-024 unit tests: dynamic status dashboard category field

Backfilled verification contract for DDD-024 (dynamic status dashboard via category field).

## Test Reference

- tests/test_autoresearch_pack.py — exercises the category field on installed pack schemas (TestPackInstall confirms category is set on COMP/LOOP/EXPT/FIND schemas and that the status dashboard groups them under the research category without code edits).
- tests/test_brief.py — exercises brief --next's category-aware counting, confirming that a pack-declared category surfaces in the dashboard without changes to status.py.
- tests/test_ac_quality.py — touches the dashboard-rendering path (status.py dynamic grouping reads schema.category) via the AC observability contract.

## Scope

DDD-024 defines the category field on schema YAMLs as the source of truth for the status dashboard's grouping. The dashboard reads category from each schema and groups artifact rows by it; packs that declare a new category need no code changes.
