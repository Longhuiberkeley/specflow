# Unit Test for DDD-012: Traceability Chain Detailed Design

## Test Cases

- [ ] Given a COMP with loops, experiments and findings, when `specflow trace <COMP>` runs, then it lists both loops, nests experiments under their loops and lists the findings; given a COMP with no findings, then none are listed
- [ ] Given links carrying the wrong role, when trace walks the research graph, then those artifacts are not attached to loops or COMPs
- [ ] Given a full REQ→ARCH→STORY→test chain, when `specflow rtm` runs, then one row fills every column; given a missing link, then the gap columns are flagged and `--gaps` shows only gap rows
- [ ] Given parent-held `refined_by` links and the legacy child-held shape, when chain depth is computed, then the parent-held refinement is followed and both shapes resolve in the matrix
- [ ] Given `specflow rtm --format csv` or `--format markdown`, when it runs, then it renders the matrix; given an unknown `--req` filter, then it exits 0
