# project-audit baseline drift compares v1.9.0->v1.9.2 despite newer baselines through v1.13.3

AUD-058 report header states "Baseline drift: compared v1.9.0 -> v1.9.2", but .specflow/baselines/ contains baselines through v1.13.3. The baseline-selection logic picks a stale pair, so suspect-flag replay for artifacts modified in v1.12.x-v1.13.x releases runs against a baseline four minor versions behind.

Lens: regulator.

Recommended actions:
1. Fix baseline selection to use the most recent baseline by default.
2. Emit a warn when the comparison baseline is older than the most recent shipped baseline.
