# Green release gate coexists with 72% chain coverage; holes concentrate in recent cycles

AUD-058 gate result is CLEAN (0 errors) while chain coverage is 72% (27 missing V-model pairs) and all 18 vertical warnings concentrate in REQs shipped in the last two release cycles (REQ-029/030/031/033/035/037, REQ-AUTORESE-d684, REQ-DEFERRED-5cea, REQ-TRANSCRI-24b7). The release ledger records "0 escalating structural warns" — accurate for errors, but readers conflate it with "no holes". The v1.13.2 silent-corruption bug was caught by an adversarial lens, not the gate.

Lenses: regulator, premortem.

Recommended actions:
1. Restate doctrine: green gate = "no new errors", and the release ledger must separately report hole count + trend (growing/shrinking vs previous audit).
2. Surface chain coverage % as a top-line report-header metric with delta-from-baseline.
3. Run adversarial lenses on every release, not as a one-off.

## Resolution Evidence

Addressed 2026-08-05 (post-v1.13.4, lands in the next release):
- Actions 1+2 implemented: every `project-audit` report header now carries a **Chain coverage** top-line metric (approved STORYs fully covered by UT+IT+QT, derived from `artifact_lint.check_coverage`'s own walk so the metric and the lint can never disagree) and a **Trend vs AUD-0XX** line with signed deltas for errors/warns/info/chain-coverage against the prior audit. Holes are reported separately from the gate result by construction — the header shows both side by side.
- Trend machinery is durable: new AUD artifacts stamp machine-readable `summary_errors`/`summary_warns`/`summary_info`/`chain_coverage_pct` fields; pre-stamp audits render an honest "predates summary stamping" fallback; informational only, exit-code semantics and `--dry-run` parity unchanged.
- Action 3 was already de-facto practice: the ship skill runs the adversarial lenses by default (AUD-058…072 all did).
- Tests: 8 new cases in tests/test_project_audit.py (mixed-coverage numbers, full/n-a variants, tally-equality vs check_coverage, stamped-trend deltas, both fallbacks, dry-run read-only trend).
