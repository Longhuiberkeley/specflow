# Audit signal design: severity asymmetry, no audit-over-audit trend, unclassified ACs at info

Consolidated audit signal-design findings from the AUD-058 adversarial wings (premortem, assumption_surfacing, regulator, temporal_drift):
- Severity asymmetry: the same problem class (REQ with ACs but zero linked tests) is warn for 8 REQs and info for ~20 others; info-classed rows mirror warn-classed CHL-338/339 debt, so triaging the warn layer leaves the debt to regenerate.
- No trend vs prior audit: nothing reports whether the 79 verification gaps are growing or shrinking between audits.
- 157 of 243 AC items are observability-unclassified (effectively unverifiable) at info severity; per-REQ rollup is too coarse to act on.
- 18/39 REQs carry no non_functional_category and every set category is "functional" — the NFR surface exists but is never exercised.
- Workflow tags (backfilled, deferred) assert no structural rule; anything tagged backfilled currently bypasses test-link expectations.

Recommend folding these into the ROADMAP Future list as a scoped "audit signal design" workstream rather than holding them as open challenges.
