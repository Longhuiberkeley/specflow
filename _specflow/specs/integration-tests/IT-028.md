# Integration Test for ARCH-025: Research-aware traceability chain

Backfilled integration test for ARCH-025 (Research-aware traceability chain).

## Test Reference

- tests/test_trace_research.py — exercises specflow trace COMP/LOOP/EXPT: the renderers walk the chain using the link roles from ARCH-023 (operates_on, belongs_to, condenses). Originally everything was derives_from, which produced wrong output; these tests trap the regression.
- tests/test_autoresearch_pack.py — exercises the end-to-end chain: specflow trace COMP walks COMP→LOOP→3 EXPTs→FIND with the correct link roles and types.
- tests/test_artifacts.py — exercises the specflow trace command's generic output format (one of the inputs the research renderers use).

## Scope

ARCH-025 defines that specflow trace must handle research artifacts (COMP/LOOP/EXPT/FIND) and use the research-specific link roles. The tests lock in:
- the renderer for COMP (walks to LOOPs and FINDs)
- the renderer for LOOP (walks to EXPTs and the parent COMP)
- the renderer for EXPT (walks to the parent LOOP)
