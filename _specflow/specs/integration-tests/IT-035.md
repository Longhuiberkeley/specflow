# Integration Test for REQ-015: Release-evidence RTM completeness

Backfilled integration test for REQ-015 (Compliance Evidence Reports) via the live evidence suite.

## Test Reference

- tests/test_evidence.py — exercises generate_evidence_report end to end: basic report generation against a baseline, loud failure on a missing baseline, the Traceability Matrix section, STORY-KEEPRELE-37de's mixed-eligible-status regression (approved, implemented, and verified REQs all render — one verified REQ must not collapse the ship-grade RTM to a single row), the Test Results Summary, the Standards Compliance section, and the baseline diff snapshot.

## Scope

REQ-015 requires a compliance evidence report whose traceability matrix is complete at release time. The evidence generator prefers verified REQs and falls back to approved/implemented only when none are verified; the first verified REQ therefore must not hide its approved and implemented peers from the ship-grade RTM.

1. uv run pytest tests/test_evidence.py -q exits 0 (recorded via specflow verify).
2. The traceability matrix retains every eligible REQ (approved, implemented, verified) when at least one is verified.
3. A missing baseline fails the report with an actionable error.
4. specflow artifact-lint --method programmatic adds 0 blocking issues.
