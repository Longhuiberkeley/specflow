# Integration Test for ARCH-027: Autoresearch skill + protocol-doc surface

Backfilled integration test for the skill + protocol-doc surface of ARCH-027 (Autoresearch pack — schema-driven capability surface).

## Test Reference

- tests/test_doc_command_examples.py — parse-guards every fenced `specflow create` example in the shipped docs under src/specflow/ and .claude/skills/: asserts the scanner finds at least 10 documented commands, then parses each one against the real CLI argparse parser. Covers the autoresearch SKILL.md examples (STORY-070), autonomous-loop-protocol.md's Phase 1/7 `specflow create` examples (STORY-071), finding-generation-protocol.md's `specflow create --type finding` examples (STORY-073), and competition-setup-protocol.md's `specflow create --type competition` examples (STORY-074). No existing IT references this suite — this artifact closes that gap.
- tests/test_autoresearch_cli.py — exercises the CLI verbs that are the executable embodiment of the 8-phase protocol surface: plan creates/updates draft LOOPs with mode/budget/knowledge_input (the explore/exploit/validate modes documented by STORY-072), run prints the loop protocol and starts draft LOOPs, review surfaces FINDs and EXPTs (STORY-073), leaderboard ranks by metric_direction and groups by change category (STORY-074), and the concurrent-LOOP gate keeps one LOOP running at a time.
- tests/test_autoresearch_pack.py — exercises the skill surface: pack install copies SKILL.md + references without overwriting user edits, and pack/base context injection writes idempotent sentinel blocks into AGENTS.md/CLAUDE.md across hosts.

## Scope

ARCH-027 defines the autoresearch pack as a schema-driven capability surface; this IT covers the surface agents read and invoke:
- the SKILL.md subcommands and protocol reference docs must stay parseable against the real CLI (no doc drift)
- the 8-phase loop protocol is executable through the autoresearch plan/run/review/leaderboard verbs
- skill installation and agent-context injection are harness-agnostic and idempotent

## Acceptance Criteria

1. uv run pytest tests/test_doc_command_examples.py tests/test_autoresearch_cli.py tests/test_autoresearch_pack.py -q exits 0 (recorded via specflow verify).
2. Every fenced `specflow create` example in the autoresearch SKILL.md and protocol docs parses against the real CLI parser.
3. The plan/run/review/leaderboard verbs work against a COMP, including the concurrent-LOOP gate.
4. specflow artifact-lint --method programmatic adds 0 blocking issues.
