# Integration Test for ARCH-018: File Traceability Layer

## Test Cases

- [ ] Given an artifact whose `output_files` names an existing file, when `artifact-lint --type output-files` runs, then no warning names it; given a missing file, then a warning names the path
- [ ] Given an `output_files` glob, when the check runs, then a pattern matching files passes and a pattern matching nothing warns

- [ ] Given `specflow update <ID> --output-files a.py,b.py`, when it runs, then the field holds exactly that list, replacing any previous value; given `--output-files ""`, then the field is removed; given an unknown ID, then it exits non-zero
