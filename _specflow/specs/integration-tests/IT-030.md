# Integration Test for ARCH-027: Autoresearch pack schema-driven capability surface

Backfilled integration test for ARCH-027 (Autoresearch pack — schema-driven capability surface).

## Test Reference

- tests/test_autoresearch_pack.py — exercises the pack lifecycle: apply_pack copies schemas + creates dirs + installs skills, the five classes cover schema lifecycle, pack install, EXPT terminal status, end-to-end chain, and skill no-overwrite.
- tests/test_autoresearch_cli.py — exercises specflow autoresearch plan/run/review/leaderboard against multi-COMP repos with the concurrent-LOOP gate.
- tests/test_autoresearch_schema.py — exercises auxiliary_metrics field round-trip and lint recognition.
- tests/test_adoption_pack.py — exercises the add_pack adoption path.
- tests/test_refresh_lints.py — exercises the refresh --all-platforms path that re-installs the pack into a multi-host project.
- tests/test_ops_pack.py — exercises the ops pack install (peer of the autoresearch pack) to confirm the pack architecture is harness-agnostic.

## Scope

ARCH-027 defines the autoresearch pack as a schema-driven capability surface:
- schemas are the contract (YAML fields define what's valid)
- CLI verbs dispatch on the schemas (plan/run/review/leaderboard)
- context injection is harness-agnostic (idempotent sentinels per host)
- the frontmatter writer is generic (--set path works for any schema)
- the lint is domain-aware (recognizes the optional fields)
