# Traceability Chain Detailed Design

## Function

The traceability chain module walks the artifact link graph bidirectionally and renders the full verification chain for any artifact. It powers `specflow trace <ID>`, the `--type chain-report` lint check, and the compliance evidence report. The chain walker starts from a seed artifact and follows upstream links (`derives_from`, `complies_with`) via BFS and downstream links (reverse-link resolution) via a full scan of the artifact corpus. Chain depth is computed as the longest reverse-link path from the seed to a leaf.

## Algorithm

The upstream walk uses breadth-first search, following `derives_from` and `complies_with` link roles from the seed artifact. A `visited` set prevents infinite loops in cyclic link graphs. The downstream walk scans all artifacts in the `id_index` dict and collects those whose links point back to the seed — this is O(N) over the corpus, acceptable for filesystem-native project sizes. The `compute_chain_depth()` function uses recursive DFS on reverse links, returning the longest path as a list of artifact IDs. Research-aware trace rendering (for COMP, LOOP, EXPT prefixes) uses role-based traversal: `operates_on` for COMP→LOOP, `belongs_to` for LOOP→EXPT and FIND→COMP, and `condenses` for FIND→LOOP.

## Data Structure

The chain is represented as a dict with two keys: `upstream` and `downstream`. Each value is a list of dicts with keys `id`, `type`, `title`, `status`, and `role`. The `id_index` is a `dict[str, Artifact]` built once per trace invocation via `build_id_index()`, enabling O(1) lookups during the walk. The depth path is a `list[str]` of artifact IDs representing the longest chain from seed to leaf.

## Invariant

The chain walker guarantees termination because the `visited` set prevents revisiting artifacts. The downstream scan is bounded by the corpus size. The chain report is purely informational — short chains are not errors because the appropriate depth depends on the user's compliance standard, aligning with SpecFlow's Bring-Your-Own-Standard philosophy.
