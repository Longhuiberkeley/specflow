## Function
Compute the zero-token research frontier for a COMP: per-lineage depth (noise-adjusted via noise-probe sigma), per-COMP width (distinct strategy families, research_agenda coverage, unexplored neighborhoods from open agenda entries plus closure-readiness seeds), stagnation states with an advisory move menu (switch formulation from the open agenda, restart with memory, landscape re-survey), revisit candidates (first-of-a-kind discards with a single attempt), and --json emission of the full ledger while the default view renders the top signals.

## Data Structure
Optional EXPT.lineage names the formulation chain; depth = chain length; noise-adjusted gain = delta versus noise-probe sigma; consecutive within-noise runs mark the lineage depth-exhausted; family identity = change_category plus strategy_family; breadth-without-depth = mean lineage depth below threshold.

## Algorithm
Load EXPT/LOOP frontmatter, group by lineage, compute per-lineage depth and within-noise streaks, compute width metrics across families and agenda, classify states, render menu plus candidates. Anchored no_op EXPTs (research_progress present, change_category analysis) are excluded from every evidence-free window before stagnation is computed.

## Error Handling
Missing lineage field: EXPTs count as singleton chains (depth 1). Missing noise probe: sigma defaults to none and noise adjustment degrades to raw deltas with a stated caveat. Empty agenda: width reports zero coverage with a re-survey suggestion rather than an error.

## Verification
Fixture COMP with seeded EXPTs exercising each state; property test that no rotation rule keyed on counts exists in the module.
