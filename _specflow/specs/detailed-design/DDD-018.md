# Body Quality Validation and File Existence Checks

Detailed design for spec body quality validation patterns and output file existence checking algorithms.

## Data Structures

```python
ARCH_SECTIONS = re.compile(r"^##\s+.*(Interface|Component|Responsibility|Data Flow|Structure|Package|Module|Dependencies)", re.I | re.M)
DDD_SECTIONS = re.compile(r"^##\s+.*(Function|Data Structure|Algorithm|Error Handling|Invariant|Precondition|Signature|Implementation)", re.I | re.M)
GLOB_CHARS = set("*?[")
```

## Algorithm: ARCH Body Quality Check

`_check_arch_body(art) -> list[str]`

1. Extract body text (content after YAML frontmatter delimiter).
2. Count words: split on whitespace, filter empty strings. If < 50: append warning "architecture description appears to be a placeholder (<words> words, minimum 50)".
3. Search for `ARCH_SECTIONS` matches. If zero matches: append warning "architecture artifact has no structural section headers (expected: Interface, Component, Data Flow, etc.)".
4. Return list of warning strings.

## Algorithm: DDD Body Quality Check

`_check_ddd_body(art) -> list[str]`

1. Extract body text.
2. Count words. If < 100: append warning "detailed design appears to be a placeholder (<words> words, minimum 100)".
3. Search for `DDD_SECTIONS` matches. If zero matches: append warning "detailed design has no design section headers (expected: Function, Data Structure, Algorithm, etc.)".
4. Return list of warning strings.

## Algorithm: REQ-to-ARCH Coverage Check

`_check_coverage_arch(artifacts) -> (blocking, warnings, details)`

1. Collect all approved REQs.
2. Collect all ARCH artifacts with `derives_from` link targets.
3. For each approved REQ: check if any ARCH lists this REQ as a `derives_from` target.
4. If not: increment warnings, append detail "REQ <id> has no architectural decomposition (no ARCH derives_from this requirement)".
5. Return counts.

## Algorithm: Story Minimum AC Check

`_check_story_min_ac(artifacts) -> (blocking, warnings, details)`

1. Filter to STORY artifacts.
2. For each story: extract Acceptance Criteria section.
3. If no AC section found: warning "story has no Acceptance Criteria section".
4. Count numbered items (`^\d+\.\s+`). If count < 2: warning "story has only <n> acceptance criteria (minimum 2 recommended)".
5. Return counts.

## Algorithm: Output File Existence Check

`_check_output_files(root: Path, art) -> list[str]`

1. Read `output_files` from artifact frontmatter. If absent or empty: return empty list.
2. For each path in `output_files`:
   a. If `any(c in path for c in GLOB_CHARS)`: skip (glob pattern, existence not verified).
   b. Resolve: `full_path = root / path`.
   c. If not `full_path.exists()`: append warning "output file not found: <path>".
3. Return list of warning strings.

## Integration with artifact_lint.py Dispatch

1. Register new check name `spec-body` in `CHECK_NAMES`.
2. In `_run_check()`, add: `elif check == "spec-body": return _check_spec_body(artifacts, root)`.
3. `_check_spec_body()` iterates all ARCH and DDD artifacts, calls type-specific body validator, aggregates results.
4. Register new check name `output-files`.
5. In `_run_check()`, add: `elif check == "output-files": return _check_output_files_all(artifacts, root)`.
6. Extend existing `coverage` check to also call `_check_coverage_arch()`.
7. Extend existing `story-size` check to also call `_check_story_min_ac()`.

## Error Handling

- Body extraction failure (malformed frontmatter): skip body quality check, log warning.
- Filesystem permission error during output_files check: report as warning (not blocking).
- Empty body text: both word count and section checks will flag appropriately.
