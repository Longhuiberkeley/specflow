# Autonomous loop protocol — 8 phases

Adapted from `autoresearch_fork/.claude/skills/autoresearch/references/autonomous-loop-protocol.md` (1030 lines). The eight phases:

| Phase | Activity | Differences from autoresearch |
|---|---|---|
| 0 | Precondition checks | + COMP exists, LOOP in draft, FINDs loaded into knowledge_input |
| 1 | Review prior state | Reads FINDs + current LOOP's EXPTs + git log (autoresearch reads TSV tail) |
| 2 | Ideate next change | + mode-aware (explore/exploit/validate); anti-patterns preserved |
| 3 | Modify (one atomic change) | Unchanged: ONE change to in-scope files |
| 4 | Commit | Unchanged: `experiment(<scope>): <description>` |
| 5 | Verify (run COMP.verify_command) | verify_command sourced from COMP artifact |
| 6 | Decide (kept/discarded/crashed/no_op) | Unchanged: crash recovery (max 3), guard rework (max 2) |
| 7 | Log | `specflow create --type experiment` (autoresearch: TSV append) + LOOP update |
| 8 | Repeat or complete | + Update LOOP status; agent reviews EXPTs and updates COMP FINDs |

## Preserved (do not modify)

- Atomicity rules (one-sentence test, file-count alert)
- Commit/revert protocol (use `git revert`, not `git reset --hard`, for discarded EXPTs)
- Verify/guard/noise handling
- Decision matrix
- Crash recovery (max 3 fix attempts, then discard)
- Stuck detection (5 consecutive discards → halt for user review)
- Rework protocol

## State persistence

LOOP artifact replaces autoresearch's `state.json`. Running totals live in `iteration_count`, `kept_count`, `discarded_count`, `best_metric`, `best_experiment` on the LOOP.
