# Deprecation Cleanup DDD

## Function

The deprecation cleanup module identifies and removes deprecated code paths, unused configuration options, and legacy artifact formats from the SpecFlow codebase. It provides the `specflow detect dead-code` command for AST-based dead code detection and the `specflow detect similarity` command for token-based code similarity analysis. These tools help maintainers safely remove obsolete functionality without breaking active features.

## Algorithm

Dead code detection uses Python's `ast` module to parse all `.py` files under `src/specflow/`. It builds a call graph by collecting function and class definitions and their references across modules. Functions and classes that are defined but never imported or called by any other module are flagged as candidates for removal. Similarity detection tokenizes function bodies using a regex-based tokenizer, computes pairwise Jaccard similarity over token sets, and reports pairs above a configurable threshold (default 0.8). Both detectors produce machine-readable output suitable for CI integration.

## Implementation

The detection commands live in `src/specflow/commands/detect.py`. Dead code detection iterates over all Python files, builds an AST index of definitions, then cross-references imports and calls to identify unreachable code. Similarity detection uses the tokenizer from `lib/dedup.py` and computes Jaccard coefficients over all function pairs. Results are printed to stdout with file paths, line numbers, and confidence scores. The `--json` flag produces structured output for automated processing. Both detectors are zero-token (pure Python, no LLM calls) and run in under a second for typical project sizes.
