# Config Merge and Version Detection Algorithm

Detailed design for the configuration merge logic, version detection, and incremental schema copy within the Init Upgrade Engine.

## Data Structures

```python
@dataclass
class VersionDelta:
    current_version: str | None
    framework_version: str
    is_upgrade: bool
    new_fields: list[str]
    deprecated_fields: list[str]
```

## Algorithm: Config Merge

`merge_config(existing: dict, defaults: dict) -> dict`

1. Start with a deep copy of `defaults`.
2. For each top-level key in `existing`:
   a. If key exists in `defaults` and both values are dicts: recurse.
   b. If key exists in `defaults` and values are lists: merge lists (deduplicate by identity).
   c. If key exists in `defaults` and values are scalars: keep `existing` value (user wins).
   d. If key does not exist in `defaults`: keep `existing` value (user custom field).
3. For each top-level key in `defaults` not in `existing`:
   a. Add with default value (new framework field).
4. Write `version` = `specflow.__version__` into merged result.

## Algorithm: Version Detection

`detect_version_delta(root: Path) -> VersionDelta`

1. Read `.specflow/config.yaml`. If missing or no `version` key: return `current_version=None`.
2. Compare `current_version` with `specflow.__version__`.
3. If equal: no upgrade needed, still merge (idempotent).
4. If different: compute `new_fields` by diffing current default_config keys vs. existing config keys.
5. Return VersionDelta.

## Algorithm: Incremental Schema Copy

`merge_schemas(src: Path, dst: Path)`

1. For each file in `src/` (recursive):
   a. Compute relative path.
   b. If `dst/<relative>` exists: skip.
   c. If not: copy file.
2. Never delete files in `dst/` that are absent from `src/` (they are user/pack-added).
3. If `--force`: backup `dst/` to `.specflow/cache/backups/<timestamp>/schemas/`, then `shutil.rmtree(dst)` and full copy.

## Algorithm: State Preservation

1. Before writing `state.yaml`: check if file exists.
2. If exists: skip entirely. Do not overwrite.
3. If `--force`: backup first, then write fresh defaults.

## Error Handling

- If `config.yaml` is corrupted (invalid YAML): log warning, treat as fresh init.
- If version string is unparseable: log warning, treat as upgrade from unknown version.
- If backup fails (disk full, permissions): abort with error, do not proceed with destructive operation.

## Implementation Files

- `src/specflow/commands/init.py` — run() modification for upgrade path
- `src/specflow/lib/config.py` — merge_config(), detect_version_delta()
- `src/specflow/lib/scaffold.py` — merge_schemas()
