# Deterministic Analytics Engine

## Function

The deterministic analytics engine computes project health metrics, coverage statistics, and compliance scores using pure Python with zero LLM tokens. It powers `specflow status`, `specflow artifact-lint`, and `specflow project-audit` by aggregating artifact counts by type and status, computing V-model verification coverage percentages, evaluating link health (broken links, orphans, missing verification pairs), and generating per-standard compliance scores. All computations are deterministic — the same artifact state always produces the same metrics.

## Algorithm

The engine uses single-pass aggregation over the discovered artifact list. For type/status counts, it iterates once and builds frequency dicts. For coverage, it pairs spec artifacts with their V-model counterparts using the `V_MODEL_PAIRS` mapping and checks for `verified_by` links in both directions. For compliance scores, it loads installed standard clauses and checks each clause for at least one artifact with a matching `complies_with` link, computing `covered / total * 100`. For link health, it builds an ID index and scans all artifact links for targets not in the index. The chain-depth metric uses recursive DFS following reverse links.

## Data Structure

The primary output is a nested dict consumed by the status dashboard renderer. It contains `by_type` (prefix → count), `by_status` (status string → count), `health` (broken, orphans, missing_pairs), and `coverage` (req_pct, story_pct, chain_pct with numerators and denominators). The `_load_categories()` function groups schema prefixes by their `category` field into a dict of lists, enabling the dashboard to render category-based sections without hardcoded type lists.
