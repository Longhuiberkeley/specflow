# Skill Prompt Optimization

## Function

The skill prompt optimization module reduces token consumption when AI agents execute SpecFlow skills by assembling minimal, context-efficient prompts. Rather than injecting the entire project context, the optimizer selects only the artifacts directly relevant to the current skill invocation — the target artifact itself, its immediate upstream and downstream links, and the relevant AGENTS.md sections. This keeps subagent prompts under the 4000-token budget defined by the executor while preserving enough context for accurate code generation and review.

## Algorithm

The optimization algorithm operates in three passes. First, it collects the seed artifact and its direct link neighbors (depth 1) from the artifact graph. Second, it scores each neighbor by relevance: artifacts sharing a `verified_by` or `specified_by` relationship with the seed receive the highest weight, while `derives_from` links receive moderate weight and tangential links receive low weight. Third, it packs artifacts into the prompt budget using a greedy knapsack approach — highest-weight artifacts are included first until the character budget is exhausted, with body truncation applied to the last artifact if it partially fits.

## Implementation

The optimizer lives in `lib/executor.py` within the `build_subagent_context()` function. It constructs a `SubagentContext` dataclass containing the story body, linked design document, linked architecture document, and a truncated AGENTS.md excerpt. The `total_chars` property enforces the budget, and the truncation logic prioritizes the story body (never truncated), then design doc, then arch doc, then AGENTS.md. The `to_prompt()` method renders the final string passed to the AI subagent.
