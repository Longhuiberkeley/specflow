# Dynamic status dashboard via category field

## Schema convention

Each schema YAML gains an optional `category:` field:

```yaml
category: spec      # default if absent
category: work
category: review
category: research
```

Existing 13 schemas get categories assigned:

- **spec**: requirement, architecture, detailed-design, unit-test, integration-test, qualification-test
- **review**: review, audit, challenge
- **work**: story, spike, decision, defect
- **research**: (added by autoresearch pack) competition, loop, experiment, finding

Optional schemas (hazard, risk, control) get `category: spec`.

## status.py changes

Replace the three hardcoded lists at lines 233, 241, 251 with a dynamic loader:

```python
def _load_categories(root: Path) -> dict[str, list[str]]:
    """Read all installed schemas and group prefixes by category."""
    categories = {"spec": [], "work": [], "review": [], "research": []}
    schema_dir = root / ".specflow" / "schema"
    for yaml_file in schema_dir.glob("*.yaml"):
        schema = yaml.safe_load(yaml_file.read_text())
        prefix = schema.get("prefix")
        cat = schema.get("category", "spec")
        if cat in categories and prefix:
            categories[cat].append(prefix)
    return categories
```

## Rendering rule

- Iterate categories in order: spec, work, review, research
- Render a row only if at least one artifact in that category has count > 0
- Preserve display labels: "Specs:", "Reviews:", "Work:", "Research:"

## File paths

- `src/specflow/commands/status.py:209-256` — replace hardcoded lists with `_load_categories(root)` call
- All 13 + 3 schema YAMLs in `src/specflow/templates/schemas/` — add one `category:` line each
