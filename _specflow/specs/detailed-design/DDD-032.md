## Function
Resolve which approved BPs are in scope for an artifact: applicability predicate (circumstance dimensions plus lifecycle moment) first, tag intersection fallback, status filter (approved) last; and stamp legacy BPs with provenance via practices migrate.

## Data Structure
Transitional map in best-practice.yaml: approved: [draft, active]; superseded: [approved, active] — the superseded expansion keeps legacy supersession edges reachable during migration. Provenance stamps: bundled for handbook-generated bodies; bodies lacking the anatomy stamp synthesized with a validation warning.

## Algorithm
Match order: applicability, then tags, then status. Migrate scans BPs without provenance, stamps per the rule above, records counts; idempotent by the presence of the stamp; --dry-run prints the would-stamp set with counts and exits 0 without writing. The loader rewrite and the map land in one release (DEC-089 coupling): pytest pins the map bytes and asserts a legacy active BP resolves through the new loader identically to the old tag-path result.

## Error Handling
BP with both applicability and tags: applicability wins; tag-only legacy BPs keep resolving. Status active on a completed legacy install: accepted by the transitional map and surfaced by migrate for stamping.

## Implementation Notes
Loader equivalence is asserted on the shipped dogfood BPs; migrate idempotency and dry-run write-free behavior are pinned in tests.
