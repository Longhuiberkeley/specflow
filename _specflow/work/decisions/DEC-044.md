### Message Body

Add the `compliance-evidence` lint check so `complies_with` links require
a substantive body (≥50 words) and at least one keyword from the clause
title/category; strict mode (config: lint.compliance_evidence_strict)
escalates warnings to blocking.

Introduce the REVIEW artifact type (REVIEW-NNN) emitted by
`/specflow-artifact-review` to summarize each review pass. Spawned CHLs
link back to the REVIEW via refers_to, and the REVIEW carries the finding
summary, depth, reviewers, and consensus fields. `specflow status` adds
a `Reviews:` line counting REVIEW + AUD + CHL artifacts.
