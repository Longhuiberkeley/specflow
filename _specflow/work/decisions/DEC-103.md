# Adopt multi-stack craft-layer and robustness practices (2026-10 landscape survey)

## Context

After pstack (DEC-102), the owner asked which other AI-coding skill stacks exist and what SpecFlow should take from them at a methodological or practical level, including whether one or two non-role-based ideation skills are worth having. A 183-agent research run on 2026-10-18 profiled 30 stacks (gstack, superpowers, BMAD-METHOD, spec-kit, OpenSpec, Agent OS, compound-engineering, humanlayer ACE, claude-flow, SuperClaude, cc-sdd, Kiro specs, Anthropic plugins, task-master, oh-my-claudecode, PRPs-agentic-eng, Ralph, OneRedOak, Conductor, context-engineering-intro, GSD, trailofbits/skills, metaswarm, moai-adk, pro-workflow, spec-kitty, flow-next, agentsys, oh-my-agent, Ring), extracted 411 practice cards, clustered them into 40 practices, judged each against the AGENTS.md design philosophy, and ran two independent refuters against every adopt verdict. Every claim adopted below was re-measured in this repository before this decision was written.

Owner decisions (2026-10-18): release the pstack tracks first as v1.17.4 (done); fold framing into `/specflow-discover` rather than add a skill; remove the `go` auto-commit; unpark DEC-102 Track 4 slice A only.

## Consequences

- Increment 1 (REQ-067) is engine code with tests and negative fixtures; increment 2 (REQ-068) is prose plus pins; both stay in the v1.17.x patch line. Framing (increment 3) gets its own DEC because it narrows the published positioning in docs/comparison.md.
- `go` no longer commits: consumers who relied on the wave commit (none known; the stub never executed work) must commit themselves. REQ-001 §6 is amended by this record rather than a backward transition (REQ-001 is implemented).
- `specflow done`'s output_files auto-capture (lib/orphans.py) keeps parsing legacy "specflow: wave N prepared [...]" commits for history; new work is attributed through `specflow update --output-files`, which the execute skill already requires.
- Learned PREVs are a project-audit cache input from this release (`_CACHE_GENERATION` 7 → 8); the challenge schema gains `resolution` and `resolution_since`, so consumers refresh schemas to use the field.
- New lint rows are accounting warnings and cannot flip `project-audit` to exit 2; the 20 legacy placeholders are fixed in the ledger, not baselined.
