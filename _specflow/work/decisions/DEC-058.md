# Revive the dormant BP/PREV learnings system (visibility + real consumption + dogfood)

## Context
SpecFlow has a learnings system — proactive BP best-practices and reactive PREV prevention patterns — that is well-wired on paper but dormant in practice. The dogfood repo held 1 BP stub + 1 real BP and 0 PREV files, so plan/execute/review/audit ran with the cupboard bare.

## Root causes
1. INVISIBLE — `specflow brief` never reported BP/PREV counts; PREV lives in `.specflow/checklists/learned/` (not under `_specflow/`), so it was invisible to `discover_artifacts` and to every digest. Nobody could see the cupboard was empty.
2. BP CONSUMPTION WAS ASPIRATIONAL — the artifact-review skill claimed `checklist-run` auto-loads BPs, but `lib/checklists.py` only loaded PREV. BPs were actually read only by `lib/ci.py` (CI context), not the local review loop.
3. BP creation is one-shot at `/specflow-discover` with no catch-up; PREV triggers are narrow (severity+technique gated) and the `done` auto-extract is rarely exercised.

## Decision
Revive the EXISTING surfaces rather than build new (the CE/superpowers "learnings recall" idea is redundant — we already have two). Four legs, all accounting-not-policing:
1. VISIBILITY — add a `Knowledge surfaces` block to `brief` (BP/PREV/FIND/CHL counts + dormancy hints). The empty cupboard is now self-evident.
2. REAL CONSUMPTION — add `_load_best_practices` to `lib/checklists.py` so `checklist-run` loads active/approved BPs by tag/`applies_to` (mirroring `ci.load_active_bp_context`), symmetric with PREV. The skill claim is now true.
3. DOGFOOD — create genuine BPs (BP-003..007: traceability, evidence-capture, deterministic-signals, accounting-not-policing, recall-before-act) and PREVs (PREV-001 from CHL-003, PREV-002 from DEC-056) so the cupboard is populated and both loops are proven end-to-end.
4. CLARIFY — add a Knowledge-surfaces block to `agent-context.md` (flows into AGENTS.md) naming BP/PREV/FIND/CHL and how each is captured + consumed.

## Rejected
Building a new CE-style learnings-recall surface — scope creep; SpecFlow already has BP + PREV. Consolidating or retiring BP vs PREV is a PHILOSOPHY CALL deferred to the user; this change keeps both and makes them work.
