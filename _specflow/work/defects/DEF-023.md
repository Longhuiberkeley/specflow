# Local pre-commit RBAC check skips a staged rename that also changes status (diff-filter=AM drops R entries)

`lib/rbac.py:195` staged_artifact_changes runs `git diff --cached --name-only --diff-filter=AM`. Git detects renames by default, so a staged `git mv REQ-a.md REQ-001.md` combined with `status: draft -> approved` is reported as R and filtered out; no role or independence check runs and the commit passes. `renumber-drafts` produces exactly this shape. ci-gate follows renames (STORY-698) but the local layer does not. Found by SPIKE-008 (R2-017).
