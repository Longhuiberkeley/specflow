# project-audit baseline drift reports a renumbered draft as removed since last baseline

`lib/baselines.py diff_baselines` reports an artifact present in baseline A under a draft slug id (e.g. STORY-ADDCLI-0e15) and in baseline B under its renumbered id (STORY-722) as one removal plus one addition. `project-audit` then emits an escalating warning 'removed since last baseline' for every draft renumbered between releases: 37 of them for v1.17.1 → v1.17.7 (23 identical fingerprints, the rest identical titles), which would fail the tag-run release gate for a rename that is routine at every ship. Found while cutting the v1.17.7 baseline (SPIKE-008 D2).
