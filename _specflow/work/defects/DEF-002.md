# CI gate judges a PR by its net base-to-head diff and the oldest commit author

H1 PerStepLegality and H2 PerStepAuthority (SPIKE-004) fail: a multi-commit PR draft->approved (non-approver)->implemented->verified (reviewer) is judged as one draft->verified transition by the oldest author; illegal hidden steps (approved->cancelled->implemented) pass; a legitimate multi-author PR is rejected. Fixed by STORY-698 (per-commit walk).
