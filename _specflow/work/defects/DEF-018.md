# reconcile ignores a refused or failed cascade and exits 0

DEF-011 made cascade-status exit non-zero on a refused or failed transition, but reconcile called cascade_status.run() and dropped the return code, and also returned 0 after an update_artifact failure. Fix: reconcile returns 1 and prints a count when any promotion or cascade fails.
