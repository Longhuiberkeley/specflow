# merge leaves a supersedes link on the target when the source ends cancelled, deprecated or unchanged

The DEF-012 fix added the supersedes link first and then picked the source's terminal status, falling back to deprecated or cancelled, or leaving it unchanged. The link stayed in every fallback. Fix: choose the source status first; add the supersedes link only when the source can move to superseded, and move it to superseded only once the link is in place.
